## 4. Criterion (c) — the file-drop is the only sanctioned transport

**What the code now states.** `run --feed <file>` reads a drop from
`campaigns/<C>/inbox/<stage>.json`, and the **file stem names the stage** — so a
mislabelled file cannot be ingested as another stage's output. The registry lives in
`internal/feed` (not `internal/pipeline`: `pipeline → boundary` is an import cycle),
and it partitions the pipeline's own stage table: every `model`/`mixed` stage is
either wired or declared unwired with a reason, and every `deterministic` stage is
refused if wired. `FeedStages` currently wires one stage (`discovery`) and
`FeedUnwired` declares the other nine by name.

The exclusivity is structural, and checkable: `feed.FeedStageFor` has exactly **one**
non-test caller in the tree — the CLI branch (`internal/cli/cmd_run.go:126`) — and
`boundary.IngestModelHypothesis` has **no CLI caller at all** (`internal/feed/feed.go:87`
says so in the code). `run` halts at a model stage and prints "feed results back
through the ingest APIs, then run again" (`internal/cli/cmd_run.go:232`); `run --feed`
is what makes that sentence executable.

**The tests:**

```
$ GOCACHE=$PWD/.scratch/gocache go test ./internal/cli -run 'TestRunFeedRefusesAnOutOfSetDrop|TestRunFeedRefusesADropOutsideTheInbox|TestRunFeedRefusesUnwiredStage' -count=1 -v
```

`TestFeedStagesPartitionThePipeline` is the one that catches a stage silently dropping
out of the handoff: it walks `pipeline.Stages`, requires exactly one of
wired/declared-unwired to hold for each model/mixed stage, requires a non-empty reason
on every declared-unwired entry, and requires `FeedStageIDs()` and `FeedStageFor` to
agree.

**Precision on the word "only".** What is proven is that the feed is the only **wired
model-stage** path and that every alternative route in the tree is refused — outside
the inbox (exit 2), unwired stage (exit 2), empty `--feed` value (exit 2, never a
silent fall-through to a full pipeline run). `ingest` remains the sanctioned path for
a model-free hypothesis payload; it records no `model.request`, so it is not a model
stage transport. Task 3's reviewer also recorded one Minor worth carrying: a drop
carrying `"stage": "learning"` records `origin_stage=learning` while its *stem* still

## 6. The grandfathering decision, as the code states it

**Refuse-new, grandfather-old — and the two halves live in two different places on
purpose.**

- **Old requests keep validating because the key is OPTIONAL in the schema.**
  `assets/schema/model_request.schema.json` still requires exactly
  `[role, model_id, prompt_version, response_schema, context_hash]`; `input_artifacts`
  and `context_artifacts` are properties, not requirements. That matters because
  `internal/trajectory/trajectory.go:34` maps `model.request` → the `model_request`
  definition and re-validates **every already-logged request in every existing
  campaign**. Making the key required would have retroactively invalidated historical
  events — a data-format change disguised as a feature.
- **New requests are refused without one because the WRITE path requires it.**
  `boundary.ValidateRequest` (`internal/boundary/boundary.go:384-386`) refuses
  `len(DeclaredInputArtifacts(request)) == 0` with `model request declares no input
  artifact set`. The schema cannot see a missing key; `minItems: 1` covers the empty
  array. The two clauses are complementary — neither is decoration.
- **The RUNBOOK states the same sentence to the operator**
  (`assets/runbook/RUNBOOK.md:945`): *"**Grandfathering:** requests logged before this
  change have no declaration and still validate (`input_artifacts` is optional in
  `model_request.schema.json`); requests written after it are refused without one."*

**The proof is structural and it is the test that names the split.**
`TestDeclaredInputSetIsRequired` drops the key entirely and asserts the refusal comes
from the **Go clause**, not from schema validation — i.e. a request in the old shape
still passes `validation.Validate` against the shipped schema and is refused only on
the write path:
