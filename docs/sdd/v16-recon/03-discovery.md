## Traps (what a plan must not break)

- **Golden surfaces:** `internal/probes/testdata/golden/surface_*.json` pin the surface byte-for-byte; symmetry output is deliberately sorted for byte-identity (`symmetry.go:19-20` comment). Any rank/row-field change regenerates goldens.
- **Python-twin goldens:** `internal/pipeline/stages.go:18` — the Stages table is "golden-tested against the Python twin"; adding stage 4/7a rows touches that golden and `internal/pipeline/golden_dispatch_test.go`.
- **Byte-pinned error text:** gate messages are asserted verbatim (e.g. `gates_test.go:139` pins the four-state blocker; `pytruthy_pin_test.go` files exist in planner, probes, protocolgraph). Rewording a refusal string breaks tests by design.
- **Probe registry ripple:** adding/renaming a probe must update `probesTable`, `anchorFields` (`registry.go:126`), `AnchorAllowed` (`registry.go:249`) and the `probe` enum in **three** places in `probe_surface.schema.json` (`:45`, `:98`, `:245`).
- **Console cap convention:** CLI dumps print ≤ `consoleRowCap = 40` rows (`cmd_probes.go:22`) with `--json` always complete — new audit/CLI output must follow it.
- **Audit section contract:** sections re-derive from artifacts and never trust the plan (`audit/sections/probesurface.go:1-4`); `register.go` is the single wiring point; the audit exit code fails on any `[section] problem` line (`cmd_audit.go:60-67`).
- **Deterministic pins:** `WEBV2_NOW`/`WEBV2_UUID` live in `internal/state/id.go` — new tranche/age fields must be derivable under those pins.
- **Existing negative tests:** `disposition_*_test.go` (81.5K in `disposition_test.go` alone), `cmd_answered_disposition_test.go`, `cmd_answered_inert_test.go` pin exactly when the B4 gate fires — loosening it for a consensus-critical tier would trip them.
- **HINT-only criticality:** `criticality.go:4` states the tier "never gates a finding" — converting it into a closure gate is a deliberate contract change that must be called out, not smuggled.
