## Conventions (how code in this area is written)

- **CLI verb to copy from:** `internal/cli/cmd_scorecard.go` — the house pattern is a `register(command{ord: N, name: "...", line: "...", run: runX})` in `init()` (cmd_scorecard.go:197-201), a `runX(root, args, r)` wrapper calling `t14Dispatch(root, r, func() error { return xCmd(...) })` (cmd_scorecard.go:130-132), `argSpec` parsing (cmd_scorecard.go:135-141), and a collect-then-render split (`scCollect`, cmd_scorecard.go:169-195; renderer in `cmd_scorecard_collect.go`/`_render.go`). Simpler older verbs parse args by hand (`runScope`, internal/cli/cmd_scope.go:281-306). The dispatcher is `internal/cli/cli.go` (`commandByName` cli.go:79, `CommandNames` cli.go:93).
- **Pure engine package to copy from:** `internal/srcclass/srcclass.go` (single-vocabulary, zero-deps, law-in-comments) or `internal/coverage/coverage_gaps.go` (campaign-state reader returning `validation.Value`). All dynamic data is `validation.Value` (ordered JSON, `jval`), never Go structs + encoding/json; schema validation is `validation.Validate(data, name, maxErrors)` (internal/validation/schema.go:96) against `assets/schema/*.schema.json`; writes go through `validation.WriteJson` / `appendJsonlChecked` (internal/validation/atomicio.go:34,104); ledger writes via `campaign.Log(kind, aid, data)` (e.g. internal/planner/archive.go:139).
- **Test file to copy from:** `internal/cli/cmd_scorecard_test.go` (same-package, `t.TempDir()` campaign fixtures via the shared `t14Campaign`-style helpers, e.g. `internal/cli/cmd_dedup_test.go:28 t15Campaign`; eval-side: `internal/evalstore/evalstore_test.go`, `internal/metrics/metrics_test.go`). Tests are table-free plain Go, never touch Docker/network/model.
- **Exact invocation:** `go test ./internal/cli -run TestScorecard -count=1` (package-scoped: `go test ./internal/metrics -count=1`). Determinism pins are `WEBV2_NOW`, `WEBV2_UUID`, `WEBV2_FINDING_IDS` (internal/version/version.go:33; `WEBV2_NOW` +00:00 format law at internal/floors/floors.go:56,69).
- **Golden surfaces to respect:** argparse-parity fixtures `internal/cli/testdata/p3_args_golden.json` (asserted by `internal/cli/cmd_p3_args_test.go:27`) hold 88 entries, each a single verb's own usage/error text — no entry embeds the full verb list (corrected 2026-09-21: this bullet said every stderr block embedded the FULL verb list); appending a new verb at a fresh ord leaves the file byte-identical, so regenerating it is a deliberate act, while renaming or re-grammaring an existing verb does require it. Audit sections are registered in one place, `internal/audit/sections/register.go:25 RegisterAll`, in pinned Python-code order.
