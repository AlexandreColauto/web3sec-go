- [20260908-i542] (tactic) Appending markdown plan chunks via `cat >>` merges the prior chunk's trailing `---` separator with the next chunk's `### Task N` heading (no newline) → grep -c '^### Task' undercounts and the plan looks incomplete. After EVERY multi-chunk append, repair with: replace lines starting `---### Task` → `---`, empty line, then the heading minus `---`.
